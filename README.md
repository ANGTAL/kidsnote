파이어폭스 확장기능에 등록된 기능의 소스입니다.
이 확장 프로그램은 키즈노트(kidsnote.com)의 로그인된 세션에서 작동하며, 사용자의 선택된 날짜 범위 내에서 알림장 및 앨범의 이미지/동영상 URL을 추출하여 다운로드합니다.

https://addons.mozilla.org/ko/firefox/addon/%ED%82%A4%EC%A6%88%EB%85%B8%ED%8A%B8-%EC%82%AC%EC%A7%84-%EB%8B%A4%EC%9A%B4%EB%A1%9C%EB%8D%94/

사용법.

이 확장 프로그램의 기능을 사용하려면 데이터(게시글)가 존재하는 키즈노트 학부모 또는 교사 계정 로그인이 필요합니다.
kidsnote.com 에 로그인하여 접속한 상태에서 확장 프로그램 아이콘을 클릭합니다.
팝업창에서 시작일과 종료일을 지정한 뒤 다운로드 버튼을 클릭합니다.
downloads 권한을 통해 확장 프로그램이 백그라운드에서 키즈노트 API를 호출하고, 미디어 파일을 사용자의 로컬 PC로 다운로드합니다.
다운로드가 완료 될때까지 팝업을 닫지 않고 기다려주세요.
